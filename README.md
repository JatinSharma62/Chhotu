# TestVault — Secure Field Testing & Digital Records

**SIH 2026 | PS ID: SIH26231 | Team: CodeX | Team ID: 142203**

## About the Project

**TestVault** is a digital companion designed to make field drug testing more **consistent, traceable, and tamper-evident**.

It uses a smartphone camera to analyse the colour response of field reagent tests, provides a **Positive / Negative / Inconclusive** result, and securely records the test details.

## Key Features

* 📷 Camera-based colour analysis
* 📍 GPS and timestamp-based test records
* 🧪 Supports multiple field reagent kits
* 🔐 Hash-based tamper-evident evidence log
* 📊 Dashboard for test history and results
* 📄 CSV export and printable reports
* 📱 Offline-first functionality
* ⚠️ Clearly separates field screening from laboratory confirmation

## How It Works

**Enter Case Details → Capture Test → Analyse Colour → Get Result → Secure Evidence Log → Export Report**

Each record contains relevant case information, operator details, location, test result, and evidence data.

## Current Prototype

The prototype is built using:

* HTML, CSS & JavaScript
* Canvas API for image processing
* Camera & Geolocation APIs
* HSV-based colour analysis
* Web Crypto API / SHA-256 hashing
* LocalStorage for offline records

## Important Note

TestVault provides **presumptive field-test results only**. Positive or uncertain results require confirmation through appropriate laboratory testing.
